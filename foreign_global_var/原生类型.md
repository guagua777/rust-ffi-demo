## 1. `use std::ffi::CString;`

### 是什么
`CString` 是 Rust 标准库提供的一个类型，专门用来表示 **C 语言风格的字符串**（以 `\0` 结尾的字节数组，即 null-terminated string）。

### 为什么需要它
Rust 的字符串（`&str` / `String`）**不以 `\0` 结尾**，而 C 代码（比如 readline 库）期望的字符串格式是：
```
字符序列 + 最后一个字节是 0x00 ('\0')
```

所以和 C FFI 交互时，必须把 Rust 字符串转换成 C 能懂的格式。

### 你代码里的用法（第 12、14 行）

```rust
let prompt = CString::new("[my-awesome-shell] $").unwrap();
//                                ↑
//                  Rust 字符串字面量 (&str)
//
//         CString::new() 会自动在末尾加一个 '\0'
//
// 内存中变成： [  '[', 'm', 'y', '-', ... , '$', '\0'  ]
//                                                     ↑
//                                            C 字符串必须的终止符
```

```rust
rl_prompt = prompt.as_ptr();
//                 ↑
//           获取指向内部字节数组的裸指针 *const c_char
//           这就是 C 代码能直接用的指针了
```

### 关键点
- **自动检查**：如果你的 Rust 字符串中间不小心包含了 `\0`，`CString::new()` 会返回 `Err`，不会生成无效的 C 字符串
- **内存管理**：`CString` 拥有所有权，当它被 drop 时会自动释放内存（所以你要小心指针的生命周期，后面会提到）

## 2. `use std::ptr;`

### 是什么
`std::ptr` 是标准库的裸指针（raw pointer）工具模块，提供了和裸指针相关的各种函数和类型。

### 你代码里的用法（第 18 行）

```rust
rl_prompt = ptr::null();
//           ↑
//     std::ptr::null() 函数
//
//     返回一个值为 0 的空指针，类型是 *const T
//     编译器会根据上下文自动推断 T 是 c_char
```

等价于 C 代码里的：
```c
rl_prompt = NULL;
```

### 为什么不直接写 `0 as *const _`？

你当然可以写成：
```rust
rl_prompt = 0 as *const libc::c_char;
```

但 `ptr::null()` 的好处是：
1. **语义更清晰** — 一看就知道"我想要一个空指针"
2. **类型自动推断** — 不用写类型转换，编译器知道赋值给 `*const c_char` 就返回对应类型的空指针
3. **还有 `ptr::null_mut()`** — 对应 `*mut T` 的空指针，区分 const/mut

### `std::ptr` 模块还提供什么（了解即可）
这个模块里还有很多有用的函数：

| 函数 | 作用 |
|------|------|
| `ptr::null()` | 创建 `*const T` 空指针 |
| `ptr::null_mut()` | 创建 `*mut T` 空指针 |
| `ptr::read(src)` | 从指针读取值（不转移所有权） |
| `ptr::write(dst, val)` | 向指针写入值 |
| `ptr::copy(src, dst, n)` | 内存拷贝（类似 C 的 memcpy，允许重叠） |
| `ptr::swap(a, b)` | 交换两个指针指向的值 |

## 结合你的代码完整流程串一遍

```rust
use std::ffi::CString;   // 提供 C 兼容字符串类型
use std::ptr;            // 提供空指针等裸指针工具

#[link(name = "readline")]
unsafe extern "C" {
    static mut rl_prompt: *const libc::c_char;
}

fn main() {
    // 1. 把 Rust 字符串变成 C 字符串 (+末尾自动加'\0')
    let prompt = CString::new("[my-awesome-shell] $").unwrap();

    unsafe {
        // 2. 获取裸指针，赋值给 readline 的全局变量
        rl_prompt = prompt.as_ptr();

        println!("{:?}", rl_prompt);

        // 3. 用 ptr::null() 把它设为空指针（防止悬垂）
        rl_prompt = ptr::null();
    }
}
```

⚠️ 顺便提一个你代码里**需要注意的点**：
第 18 行在把 `rl_prompt` 设为 null 之前，`prompt` 这个 `CString` 一直活着还好。
但如果顺序反了（先 drop `prompt` 再用 `rl_prompt`），就会变成**悬垂指针（dangling pointer）**，导致未定义行为。FFI 里要特别注意 Rust 值的生命周期和裸指针使用的先后顺序。
