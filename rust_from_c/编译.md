## 编译命令

在C文件的注释中已经给出了基础命令（c_callback.c:15），但需要注意**库名要和Rust代码中的链接名匹配**。

### 1. 基础编译命令

在项目目录 `/home/guagua/rust/rust_from_c` 下执行：

```bash
# 注意：Rust代码中 link(name = "extlib")，所以库名应该是 libextlib.so
gcc -fPIC -shared -o libextlib.so c_callback.c
```

### 2. 参数说明

| 参数 | 作用 |
|------|------|
| `-fPIC` | 生成位置无关代码（Position Independent Code），这是编译动态库的必要选项 |
| `-shared` | 告诉编译器生成共享库（动态库）而不是可执行文件 |
| `-o libextlib.so` | 指定输出文件名，**必须以 `lib` 开头**，Rust的链接器才能找到 |

## ⚠️ 关键注意点

### 库名必须匹配

Rust代码 `call_c.rs:5` 中指定的是：
```rust
#[link(name = "extlib")]
```

所以你的动态库文件名**必须**是：
- Linux: `libextlib.so`
- macOS: `libextlib.dylib`  
- Windows: `extlib.dll`
