# 1、apt安装 libsnappy 默认路径
Ubuntu apt 安装系统库标准位置：
- 头文件：`/usr/include/snappy.h`
- 静态/动态库：`/usr/lib/x86_64-linux-gnu/`
> 64‑bit Ubuntu 库目录固定为 `x86_64-linux-gnu`

## 所以你的 build.rs
```rust
// 告诉rustc去哪里搜索snappy库
println!("cargo:rustc-link-search=/usr/lib/x86_64-linux-gnu");
// 链接 snappy
println!("cargo:rustc-link-lib=snappy");
```

# 2、更推荐：不用手写路径
系统标准库目录编译器本身就自带搜索路径，**build.rs 只需要写链接指令即可**
```rust
println!("cargo:rustc-link-lib=snappy");
```
`/usr/lib`、`/usr/lib/x86_64-linux-gnu` 属于编译器默认搜索目录，不需要手动 `rustc-link-search`

# 3、查看库文件真实位置命令
```bash
# 查询安装位置
dpkg -L libsnappy-dev
```
你会看到输出类似：
```
/usr/include/snappy.h
/usr/lib/x86_64-linux-gnu/libsnappy.so
/usr/lib/x86_64-linux-gnu/libsnappy.a
```

# 4、如果你想要稳妥兼容写法（build.rs）
```rust
// x86_64 ubuntu
#[cfg(target_arch = "x86_64")]
println!("cargo:rustc-link-search=/usr/lib/x86_64-linux-gnu");

println!("cargo:rustc-link-lib=snappy");
```

# 5、Cargo.toml 方式（备选）
如果你使用 `snappy‑rs` / 原生绑定包一般不需要手动 build.rs；
如果你手动 FFI 绑定，上面配置就够用。

# 6、检查能否正常链接
```bash
ldconfig -p | grep snappy
```
正常输出动态库路径即代表环境就绪。

## 补充：arm64(aarch64) Ubuntu
arm64 库路径不一样：`/usr/lib/aarch64-linux-gnu`
```rust
#[cfg(target_arch = "aarch64")]
println!("cargo:rustc-link-search=/usr/lib/aarch64-linux-gnu");
```
